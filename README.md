# 코어-위성 포트폴리오 앱 (MVP)

「주식앱 PDCA 기획서」의 1단계(MVP)를 구현한 앱입니다.
시세를 대신 보고, 규칙(투자정책서)을 지키게 도와주는 것이 목적입니다. 매매 주문 기능은 없습니다.

## 실행 (Windows)

1. Python 3.10 이상 설치 (https://www.python.org — 설치 때 "Add python.exe to PATH" 체크)
2. 이 폴더의 **run.bat** 더블클릭
3. 브라우저에 앱이 열립니다 (http://localhost:8501)

처음 한 번은 패키지 설치로 1~2분 걸립니다. 이후에는 바로 열립니다.

## 처음 할 일 (15분)

1. **투자정책서 확정** — `config/ips.yaml` 을 메모장으로 열어 목표 비중·한도를 본인 기준으로 수정
   (합계 100%가 아니면 앱이 오류로 알려줍니다)
2. **보유 종목 입력** — 앱의 `보유 종목` 탭에서 수정 후 저장 (또는 `data/holdings.csv` 직접 편집)
   - 처음 실행하면 `data/holdings.example.csv`(가짜 예시)가 `holdings.csv`로 복사됩니다. 본인 보유로 바꾸세요.
   - `holdings.csv`·`journal.db`·`history.db`는 개인 정보라 git에 올리지 않습니다(.gitignore).
   - 한국 종목: 6자리 코드 + 시장 `KR` (평단은 원화)
   - 미국 종목: `avg_fx`(평균 매입 환율)를 넣으면 원화 손익·양도세가 정확해집니다 (증권사 잔고의 매입환율)
   - 현금: 티커 `CASH`, 수량 = 달러 금액, 평단 1
   - 계좌 A = 은퇴계좌(지수만), B = 일반계좌(개별주)
   - 위성 종목은 섹터와 **보유 사유 한 문장**을 꼭 입력 (없으면 감점)
3. `대시보드` → `이번 달 적립` → `계좌 검진` 순서로 확인

## 기능 (기획서 모듈 번호)

| 탭 | 모듈 | 하는 일 |
| --- | --- | --- |
| 대시보드 | M1·M2 | 총자산, 자산군 현재 vs 목표 비중, 밴드 이탈 |
| 원화·세금 | M12 | 원화 기준 손익(주가 효과 + 환율 효과), 올해 해외주식 양도세 추정, 공제 250만 원 채우기·손실 상계 후보 |
| 이번 달 적립 | M2 | 적립금을 모자란 자산군부터 배분, 위성은 7% 한도 여유에 비례, 리밸런싱 점검 |
| 계좌 검진 | M3·M9 | 포트폴리오 건강 점수(100점), 비중 초과 종목 조치(매도·절반 매도·적립 희석 금액, 상승 초과는 감점 완화), 고점 대비 -20% 종목에 물타기 4단계 게이트 |
| 매수 이유 점검 | M11 | 위성 종목별 90일마다 '깨지는 조건' 기준 점검(유지·주의·깨짐), 기한 지나면 대시보드 알림 |
| 투자일기 | M4 | 매수 체크리스트 4칸 필수, 금지 상품 차단, 규칙 위반 기록 → 준수율. 저장 시 보유 종목 수량·평단 자동 반영, 매도 실현 손익·연간 합계 |
| 성과 비교 | M10 | 날짜별 자산 기록, 위성·코어 수익률 vs 벤치마크(VOO) — 위성이 제값을 하는지 검증 |
| 보유 종목 | M1 | 보유 종목 편집 |
| 투자정책서 | IPS | 현재 규칙 보기 |

## 폴더 구조

```
stock-app/
├─ app.py              화면 (Streamlit)
├─ config/ips.yaml     투자정책서 = 앱의 규칙
├─ data/holdings.csv   보유 종목 (개인, git 제외 · 예시: holdings.example.csv)
├─ data/journal.db     투자일기 (자동 생성)
├─ data/history.db     날짜별 자산 기록 (앱 열 때마다 자동 저장)
├─ core/               계산 엔진 (ips, prices, portfolio, balancer, health, journal)
└─ tests/              단위 테스트 (python -m pytest)
```

## 알아둘 점

- 시세는 yfinance(무료, 약 15분 지연)입니다. 실패하면 마지막 캐시 → 평단으로 계산하고 화면 상단에 표시합니다.
- 15분마다 자동 새로고침되며, 즉시 갱신은 우상단 메뉴 → Rerun.
- 계좌 검진의 '이익 추정 하향' 항목은 컨센서스 데이터가 필요해 2단계에서 추가합니다.
